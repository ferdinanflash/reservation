# Feature map: Themes, translations and PWA

## Theme system

- Main UI/styles and theme selectors: `index.html`, `style.css`, and relevant logic in `js/app-core.js` / other UI modules.
- Shared theme selection is stored in `public.theme_settings`; the migration documents a shared President theme override and Realtime publication.
- Theme values in migrations include auto, halloween, christmas, valentine, cny, eid, midautumn, bluefire, thanksgiving and none (the allowed set evolves through ordered migrations).
- Theme/banner assets are stored in repository root. Seasonal video/image assets are loaded by the frontend visual logic.
- Theme SQL files: `supabase_migration_theme_settings.sql`, `supabase_migration_theme_valentine.sql`, `supabase_migration_theme_cny.sql`, `supabase_migration_theme_eid.sql`, `supabase_migration_theme_midautumn.sql`, `supabase_migration_theme_bluefire.sql`, `supabase_migration_theme_thanksgiving.sql`.

Do not infer the final live CHECK constraint from a single historical migration. Read migrations in order and inspect the live schema before changing theme values.

## Translation system

- Central dictionary and language selection: `lang.js`.
- Supported language codes found in current source: `en`, `cn`, `id`, `ph`, `th`, `it`, `ru`, `fr`.
- Feature modules call shared translation helpers/keys. Dynamic labels in JS and HTML data attributes may both require updates.
- UI width/overflow is a separate concern from dictionary completeness: test long Russian/French labels and CJK/Thai rendering after text changes.

## PWA and cache

- `index.html`: build marker `APP_BUILD`, versioned script URLs and PWA metadata.
- `sw.js`: service worker cache lifecycle and fetch strategies.
- `site.webmanifest`: install metadata.
- `opening-animation.js`, `fire-banner.js`: startup and visual banner effects.
- Icons and seasonal banners/videos are tracked root/image assets.

## Change-impact checklist

- [ ] Update all 8 language dictionaries and all dynamic translation keys.
- [ ] Check labels that are generated by JavaScript, not just static HTML.
- [ ] Test long labels, headers, buttons and modal widths on mobile.
- [ ] Test every active theme; theme-specific CSS can override base selectors.
- [ ] If assets or script behavior changes, inspect service-worker cache names/precache and URL version query parameters.
- [ ] Bump `APP_BUILD` for Safari/WebKit cache-bust behavior when deploying a fix, as documented in `index.html`.
- [ ] Verify install/update behavior and offline fallback after cache changes.
