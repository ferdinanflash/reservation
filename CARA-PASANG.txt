Perubahan SvS Enemies (rate limit + error per State + cache di Supabase)

File dalam zip ini (timpa / tambahkan ke repo dengan path yang sama):
  js/app-svs-enemies.js
  style.css
  sw.js  (CACHE_VERSION 2026-11-08-3)
  index.html  (?v= style.css 113, app-svs-enemies.js 20)
  supabase/functions/wosatlas-states/index.ts
  supabase_migration_svs_enemy_cache.sql   (file baru)

Urutan pasang:
1. Jalankan supabase_migration_svs_enemy_cache.sql di Supabase SQL Editor.
2. Deploy ulang edge function:  supabase functions deploy wosatlas-states
3. Deploy file web (js + css) seperti biasa.

Cara kerja: saat user membuka halaman, web membaca cache di Supabase.
- Data <= 120 menit: langsung dipakai.
- Data > 120 menit: web meminta edge function mengambil ulang dari WoS Atlas,
  cache di Supabase diperbarui (ditulis hanya bila isinya berubah), lalu data
  baru ditampilkan. Kalau gagal / lebih dari 45 detik, data lama tetap tampil.
- Cache kosong: diambil sekali, lalu disimpan.
Cron per jam bersifat opsional (komentar di akhir file SQL), tidak wajib.

WOSATLAS_API_KEY tidak wajib. SUPABASE_SERVICE_ROLE_KEY sudah otomatis
tersedia di edge function.
